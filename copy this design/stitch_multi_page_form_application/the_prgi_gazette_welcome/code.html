Verification Engine Stages

STAGE I

Normalization

Converts raw submitted text into consistent forms so phonetic, edit-distance, and rule checks operate on clean strings. Strips punctuation and specific stopwords.

STAGE II

Phonetic Encoding

Catches "sounds-alike" titles that pass a pure spelling check using Double Metaphone to return primary and secondary codes per word.

STAGE III

Semantic Embeddings

Catches titles with the same meaning even if spelled differently or in a different language, utilizing a 109-language cross-lingual sentence transformer.
